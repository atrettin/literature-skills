# Dependency of the find-papers skill. Install it into the Python environment
# of whichever project the skill is used from. The search itself needs nothing:
# arXiv is reached with urllib and xml from the standard library.
#
# This one is optional. Without it, the results are ordered by how many of the
# question's words each abstract carries, which ranks a paper that repeats the
# question above one that answers it. With it, a cross-encoder reads the
# question and the abstract together and orders them by the answer.
#
# It runs on ONNX Runtime and not on torch: about 60 MB installed, and a 21 MB
# model downloaded on first use and cached under ~/.cache/flashrank.
flashrank>=0.2.9
